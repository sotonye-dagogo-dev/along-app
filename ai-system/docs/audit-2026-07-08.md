# Codebase Audit — 2026-07-08

> Generated by update-ai-system.md post-execute. Identifies gaps, conventions issues, over/under-implementations across `app/`.

---

## Critical Issues (Must Fix)

### C1. Missing `/api/auth/forgot-password` Route
- **File:** `app/(public)/forgot-password/page.tsx:23` — calls `fetch("/api/auth/forgot-password")` but the API route does not exist in `app/api/auth/`.
- **Impact:** Password reset flow completely broken.
- **Fix:** Create `app/api/auth/forgot-password/route.ts` with token generation, email sending, and a reset page.

### C2. OTP Leaked via console.log
- **File:** `app/api/auth/register/route.ts:93` — `console.log(\`[DEV] OTP for ${email}: ${otp}\`)` leaks the one-time password to stdout.
- **Impact:** Any process watching server logs can read user OTP codes.
- **Fix:** Remove the log or guard behind `NODE_ENV !== "production"`.

### C3. Bookmarks Page Always Empty
- **File:** `app/(dashboard)/bookmarks/page.tsx:52-53` — fetches `/api/posts?limit=50` but ignores the response, hardcoding `setBookmarks([])`.
- **Impact:** Bookmarks tab always shows "No bookmarks yet" regardless of actual bookmarks.
- **Fix:** Replace `setBookmarks([])` with `setBookmarks(data.posts ?? [])`.

### C4. Other User Profile Page Fakes Data
- **File:** `app/(dashboard)/profile/[username]/page.tsx:48-77` — constructs fake profile from post author fields instead of calling `/api/users/{username}`. `mutualCount` state at line 44 is always 0.
- **Impact:** Other users' profiles show incomplete/inaccurate data.
- **Fix:** Add a real API fetch for the target user's profile data.

### C5. No Rate Limiting on Auth Endpoints
- `app/api/auth/login/route.ts`, `register/route.ts`, `otp/route.ts`, `refresh/route.ts`, `google/callback/route.ts` — all have zero rate limiting.
- **Config:** `app/lib/config/rateLimits.ts:7-9` defines `RATE_LIMITS.auth = { windowMs: 900000, maxRequests: 10 }` but it is never imported or enforced.
- **Impact:** Brute-force login, mass account creation, OTP brute-force all possible.
- **Fix:** Wire a shared rate-limiter middleware or inline check into each auth route.

### C6. Race Conditions in Async Effects
- **Files:**
  - `app/(dashboard)/notifications/page.tsx:54-70` — stale data if tab changes during fetch
  - `app/(dashboard)/bookmarks/page.tsx:49-61` — stale data
  - `app/(dashboard)/profile/page.tsx:59-76` — stale profile if authUser.id changes
  - `app/(dashboard)/posts/[id]/page.tsx:105-127` — wrong post data if navigating between posts quickly
  - `app/admin/users/page.tsx:42-44` — overlapping search fetches
  - `app/providers/I18nProvider.tsx:37-61` — stale locale files
- **Impact:** Users see wrong data when interacting quickly.
- **Fix:** Add AbortController to each `useEffect` fetch, abort on cleanup.

### C7. Empty Catch Blocks Silently Swallowing Errors
- **20+ locations** across all admin pages, profile pages, invite page, explore page, bookmarks, notifications. Pattern: `catch { /* ignore */ }`.
- **Files:** `app/admin/*/page.tsx` (all 7 pages), `app/(dashboard)/profile/page.tsx:73,85,96`, `app/(dashboard)/invite/page.tsx:46`, `app/(dashboard)/explore/page.tsx:118`, `app/(dashboard)/analytics/page.tsx:62`.
- **Impact:** All failures are invisible to both developer (no Sentry capture) and user (no toast).
- **Fix:** Replace with at-minimum `console.error` + Sentry capture + user-facing toast.

## Moderate Issues (Should Fix)

### M1. Mixed Named/Default Exports
- **Files:** `app/components/ui/index.ts` — 14 named re-exports, 17 default-then-rename re-exports. Feature component indexes also mixed.
- **Impact:** Import consistency is unpredictable; devs must check each component's export style.
- **Fix:** Choose one style (recommended: named exports) and convert all files.

### M2. Missing `width`/`height` on `<img>` Tags (CLS)
- **Files:**
  - `app/(dashboard)/posts/[id]/page.tsx:371` — route photo
  - `app/components/features/posts/PostCard.tsx:308,314,321,323,325` — all post images
  - `app/components/ui/ImageLightbox.tsx` — expanded image
- **Impact:** Layout shift (CLS) as images load, hurting Core Web Vitals.
- **Fix:** Add explicit `width`/`height` attributes or use Next.js `<Image>` with `fill`.

### M3. Client-Side-Only Auth Guards
- **Files:** `middleware.ts` checks cookie presence but does NOT verify JWT signature. All admin/dashboard pages rely on client-side `useEffect` redirect.
- **Impact:** Users with JS disabled can see protected content. The admin shell checks `role` only client-side.
- **Fix:** Add server-side JWT verification to middleware; add role check to admin middleware or layout.

### M4. `console.log` in Email Service
- **Files:** `app/lib/services/emailService.ts:51,52,86,104,123,142,161` — dumps email subject and body content to console when templates are missing.
- **Impact:** Noisy logs; sensitive email content leaked to stdout.
- **Fix:** Guard behind `NODE_ENV !== "production"` or remove entirely.

### M5. PostCard Multiple State Updates
- **File:** `app/components/features/posts/PostCard.tsx:97-103` — 5 independent `useState` setters called sequentially per like/dislike/bookmark interaction, causing 5+ re-renders per tap.
- **Impact:** Unnecessary re-renders on the primary feed component.
- **Fix:** Combine related state into a single reducer or batch with `unstable_batchedUpdates`.

### M6. Props Drilling — Redundant `currentUserId`
- **File:** `app/(dashboard)/home/page.tsx:180-188` — passes `currentUserId` as prop to `PostCard`, but `PostCard` line 103 reads `AuthContext` directly.
- **Impact:** Unnecessary prop and re-renders when `currentUserId` changes.
- **Fix:** Remove the prop from `PostCard` and let it read auth context.

### M7. Missing `aria-label` on Interactive Elements
- **Files:**
  - `app/(dashboard)/explore/page.tsx:537` — "Near me" button
  - `app/(dashboard)/explore/page.tsx:277,319` — search inputs
  - `app/(dashboard)/home/page.tsx:167` — clickable div with no `role="button"`
- **Impact:** Screen reader users cannot interact with these elements.
- **Fix:** Add `aria-label` or `role` attributes.

## Lower Issues (Nice to Fix)

### L1. Redundant Fragments
- **Files:** `app/providers/PushProvider.tsx:21`, `app/providers/CookieConsentProvider.tsx:7-10`, `app/(public)/forgot-password/layout.tsx:10` — wrap children in `<>...</>` unnecessarily. Can just return `children`.
- **Fix:** Remove fragment wrappers.

### L2. Hardcoded Dev JWT Secrets
- **File:** `app/lib/utils/auth.ts:4-6` — `|| "dev-jwt-secret"` fallback. Low risk (server-side only) but poor practice.
- **Fix:** Remove fallback and throw if env var missing in production.

### L3. Large Hardcoded Data Arrays (Config)
- **Files:** `app/lib/config/faq.ts`, `app/lib/config/emptyStates.ts`, `app/lib/config/vehicles.ts` — large inline data structures. Acceptable in config files but borderline for `faq.ts`.
- **Fix:** Optionally move FAQ data to a JSON file.

### L4. Explore Page Complexity
- **File:** `app/(dashboard)/explore/page.tsx` — 560 lines, single component with inline SVG, drag handling, responsive views, filters, bottom sheet, marker clustering logic.
- **Impact:** Hard to maintain, test, or modify.
- **Fix:** Split into smaller components (ExploreMap, ExploreFilters, ExploreBottomSheet, etc.).
